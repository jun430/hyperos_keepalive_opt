# 澎湃内存管理优化

HyperOS3 后台保活模块，作者：雨色，版本 2.0.0。

## 功能

1. 关闭四层主动回收（mimd、mi_reclaim、unfairmem、memory_standard），停掉小米预判性杀后台，保活核心。

2. lmkd 保守化，三档阈值可调，只杀缓存进程，不碰活跃后台。

3. 内存水位控制，内存占到设定水位才清理缓存，含迟滞避免反复清理。

4. 游戏模式，游戏前台时自动清理无关缓存后台并清文件缓存，给游戏腾内存。

5. 后台保活白名单，复用小米锁后台机制，名单内应用永不杀但可清缓存。

6. WebUI 图形配置，液态玻璃外观，跟随系统主题，参数全中文。

7. 中文日志，分级记录加心跳，256KB 自动轮转。

纯 shell 实现，无额外依赖，不碰 CPU 调度，开销近乎为零。
