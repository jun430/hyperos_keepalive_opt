# 澎湃内存管理优化

HyperOS3 后台保活模块，作者：雨色，版本 2.3.0。

## 功能

1. 关闭四层主动回收（mimd、mi_reclaim、unfairmem、memory_standard），停掉小米预判性杀后台，保活核心。

2. lmkd 保守化，三档阈值可调，只杀缓存进程，不碰活跃后台。

3. 智能保活，App 在最近任务里就给内核级保护（oom_score_adj 设为 -900，低于 LMK 任何档位），从最近任务划掉就自动撤销保护交回系统，重新打开自动恢复。保护范围覆盖主进程和全部子进程。

4. 消息通道常驻保护，QQ 的 :MSF、微信的 :push、小米推送 com.xiaomi.xmsf 这类消息投递通道单独识别，划掉后台也不撤销保护，保证后台能收到消息和通知。只对第三方 App 和推送通道生效，系统应用和系统服务一律不动。

5. 内存水位控制，内存占到设定水位才清理缓存，含迟滞避免反复清理。清理走内核定量回收接口，按 MB 指定回收量，不产生 CPU 尖峰。

6. 游戏模式，游戏前台时自动清理无关缓存后台并清文件缓存，给游戏腾内存。

7. 后台保活白名单，复用小米锁后台机制，名单内应用永不杀但可清缓存。

8. WebUI 图形配置，液态玻璃外观，跟随系统主题，参数全中文。

9. 中文日志，分级记录加心跳，256KB 自动轮转。

纯 shell 实现，无额外依赖，不碰 CPU 调度，开销近乎为零。

## 与其他 swap 模块共存

本模块不接管 swappiness、watermark_scale_factor 等 VM 参数，交由 Scene 等 swap 管理模块处理，避免两边抢写导致数值反复跳变。模块只做后台保活、缓存回收和游戏腾内存。
